## Построение графа зависимостей пакетов
**Выполнила:** Грабенко Алёна Андреевна, ИКБО-42-25
**Цель:** разработать инструмент для построения графа зависимостей пакетов на основе данных репозитория Ubuntu, с поддержкой тестового режима и визуализации графа.
## Этап 1. Разработка и проверка конфигурации
### Цель этапа
Реализовать обработку параметров командной строки и проверку корректности конфигурации перед выполнением программы.
### Реализованные функции
- Обработка аргументов командной строки с помощью библиотеки `argparse`.
- Указание имени пакета для построения графа зависимостей.
- Настройка адреса репозитория Ubuntu.
- Поддержка тестового режима.
- Указание файла с тестовым графом.
- Настройка выходного файла.
- Возможность включения ASCII-дерева.
- Выбор этапа выполнения программы.
- Проверка корректности введённых параметров.
- Вывод сообщений об ошибках при некорректной конфигурации.
### Пример запуска
```bash
python src/main.py --package bash --stage 1
```
### Результат выполнения
На первом этапе программа проверяет параметры запуска и выводит информацию о выбранной конфигурации.
