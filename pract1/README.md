## Задача 1. Вывод отсортированного списка пользователей
**Условие:**  
Вывести отсортированный в алфавитном порядке список имён пользователей в файле `passwd`.
**Решение (файл `task1.sh`):**
```bash
#!/bin/bash
grep -o '^[^:]*' /etc/passwd | sort
```
**Результат работы:**

На скриншоте показан вывод команды grep и sort — список имён пользователей, отсортированный по алфавиту.

## Задача 2. Вывод 5 наибольших портов
**Условие:**  
Вывести данные `/etc/protocols` в отформатированном и отсортированном порядке для 5 наибольших портов.
**Решение (файл `task2.sh`):**
```bash
#!/bin/bash
grep -v '^#' /etc/protocols | awk '{print $2, $1}' | sort -nr | head -n 5
```
**Результат работы:**

На скриншоте показан вывод команды: 5 протоколов с наибольшими номерами портов, отсортированные по убыванию. Формат вывода - номер порта и имя протокола.

## Задача 3. Программа banner
**Условие:**  
Написать программу `banner` средствами bash для вывода текста в рамке. Размер рамки должен меняться в зависимости от длины текста.
**Решение (файл `banner`):**
```bash
#!/bin/bash
text="$1"
len=${#text}
line="+"
for ((i=0; i<len+2; i++)); do line="${line}-"; done
line="${line}+"
echo "$line"
echo "| $text |"
echo "$line"
```
**Результат работы:**

На скриншоте показан вывод программы banner с текстом "Hello from RTU MIREA!". Рамка автоматически подстроилась под длину текста.

## Задача 4. Вывод всех идентификаторов
**Условие:**  
Написать программу для вывода всех идентификаторов (по правилам C/C++ или Java) в файле (без повторений).
**Решение (файл `task4.sh`):**
```bash
#!/bin/bash
grep -oE '[a-zA-Z_][a-zA-Z0-9_]*' "$1" | sort -u
```
**Результат работы:**

На скриншоте показан вывод программы для файла hello.c - все уникальные идентификаторы, отсортированные по алфавиту.

## Задача 5. Регистрация пользовательской команды
**Условие:**  
Написать программу для регистрации пользовательской команды (правильные права доступа и копирование в `/usr/local/bin`).
**Решение (файл `reg`):**
```bash
#!/bin/bash
if [ -z "$1" ]; then
    echo "Использование: $0 <файл_программы>"
    exit 1
fi
if [ ! -f "$1" ]; then
    echo "Файл $1 не найден"
    exit 1
fi
chmod +x "$1"
sudo cp "$1" /usr/local/bin/
echo "Команда $1 успешно зарегистрирована в /usr/local/bin"
```
**Результат работы:**
На скриншоте показана регистрация программы banner с помощью ./reg banner, проверка наличия файла в /usr/local/bin и запуск команды banner из любого места.
